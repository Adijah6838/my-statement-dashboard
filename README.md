# My Statement – Full-Stack Financial Dashboard

A full-stack personal financial dashboard that allows authenticated users to view their account balance, browse financial statements, navigate transaction history, and manage account information.

## Tech Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Python, FastAPI, SQLAlchemy, Pydantic
- **Database:** SQLite (Development)
- **Authentication:** JWT, Passlib (bcrypt)
- **Testing:** Pytest, Vitest, Playwright

## Project Structure
- `/backend` - FastAPI application
- `/frontend` - React application
- `/docs` - API documentation and screenshots
